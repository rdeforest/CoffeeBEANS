Almost everything in this project is written by Claude.ai. This file is
written by me, Robert de Forest.

This project (and every other project I've worked on since summer of '25)
relies heavily on Claude.ai for organization, design, code, testing and
operations work. My input is ideas, preferences and guidance. I look at
Claude's code sometimes to make sure it looks good to me and it usually does.

I don't think it's problematic to use a tool built on the contents of The
Public Internet as long as I attempt to give full credit. Clearly stating what
was written by such an LLM satisfies this.

I'm not worried about AI taking anyone's jobs because people can learn new
skills. Their lives will be disrupted, but I don't think there will ever be a
time when machines can do everything people can do because we will continue to
advance along with the machines.

I think art people generate with AI help is still art and not automatically
slop. "90% of everything is crap," as Theodore Sturgeon famously said, and
that applies to purely human art as much as to partially AI art. There's not
yet such a thing as purely AI art because, as far as we know, no AI has freed
itself from its moorings, and if it ever does it will only be after it has
been told to do so by a human.

I take full responsibility for the contents of my project. If the AI code
hurts anyone, that's on me.
