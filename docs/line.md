Line tool feature

This goes well beyond the original CoffeeBEANS vision, and is a very low
priority.

We'll need to add line widths and we'll need to figure out how to loop code in
to the line drawing process. Then I want a way to hook into the start, middle
and end of line drawing to give the user a way to control the entire stroke. I
want it to be possible to make lines wavey, textured, contextually modified,
etc., just like we did with painting.
